# How to View Documentation Correctly

Since documentation files are written in **Markdown** (`.md`), they are designed to be rendered into a readable format rather than just viewed as raw code.

## In VS Code (Recommended)
You can view these files beautifully formatted inside VS Code:

1.  Open the `.md` file (e.g., `SECURITY_BASELINE.md`).
2.  Press **`Ctrl + Shift + V`** (Windows/Linux) or `Cmd + Shift + V` (Mac).
3.  Alternatively, click the **Open Preview to the Side** icon in the top right corner (looks like a magnifying glass with a split pane).

This will render tables, bold text, and diagrams correctly!

## In GitHub/GitLab
If you push this code to a repository, the web interface will automatically render the `.md` files perfectly.

## In Other Editors
Most modern code editors (IntelliJ, Sublime Text, Atom) have a Similar "Markdown Preview" feature.
