# QA Handoff Checklist

## Goal

Provide the minimum handoff package needed before MVP QA sign-off starts.

## Checklist

- MVP scope is frozen for the test cycle
- acceptance criteria exist for each workflow area
- permission matrix exists
- publication rules are documented
- evidence inventory is documented
- standards coverage caveats are documented
- localized benchmark-pack rules are documented
- test environment assumptions are documented
- open defects and risk acceptances are listed
- sign-off owners are named

## Required Attachments

- acceptance criteria document
- permission matrix
- evidence traceability matrix
- publication control rules
- benchmark-pack validation rules
- test cycle status report
