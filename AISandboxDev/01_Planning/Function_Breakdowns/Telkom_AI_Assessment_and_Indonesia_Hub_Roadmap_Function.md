# Function Breakdown: Telkom AI Assessment and Indonesia Hub Roadmap

## 1. Goal

Define the long-term product direction for the AI Sandbox as a trust, assurance, and decision-support platform, while keeping the immediate rollout focused on assessing `Telkom AI`.

## 2. Assumptions

- `Telkom AI` is the first practical model target.
- The sandbox will evolve from model evaluation into broader application and agent evaluation.
- `Apilogy` remains the capability marketplace while the sandbox owns trust scoring.
- Internal builders and governance teams both need usable outputs from the same evidence base.

## 3. Scope

- Long-term vision and product layers.
- MVP definition, architecture, benchmark package, scoring model, and rollout plan.
- Indonesia localization and expansion path after MVP.

Out of scope:

- Immediate delivery of all long-term layers.
- Full runtime protection platform in MVP.
- Broad non-LLM capability benchmarking on first rollout.

## 4. Risks

- Long-term roadmap dilutes focus from the MVP.
- Scoring dimensions are not operationalized into review decisions.
- Rollout depends on localization assets that are not yet curated.
- The platform promises application and agent coverage before the model layer is stable.

## 5. Subtasks

- Separate MVP must-have capabilities from roadmap extensions.
- Convert the MVP architecture into delivery epics and dependencies.
- Finalize the first benchmark package and scoring logic for `Telkom AI`.
- Define rollout checkpoints from endpoint registration to recommendation output.
- Define how model scores expand later into application and agent assessments.

## 6. Subtasks for Product_UI (`02_Product_UI`)

- Design the MVP scorecard, ranking, and model profile views aligned to the roadmap's score dimensions.
- Create builder-facing model comparison and recommendation views.
- Prepare extension points for later application and agent assessment modules without exposing them in MVP.

## 7. Subtasks for QA_Docs (`03_QA_Docs`)

- Document MVP scoring methodology and evidence expectations.
- Create rollout checklist for the `Telkom AI` first assessment.
- Define review criteria for safety, privacy, security, readiness, and compliance evidence coverage.
- Document roadmap assumptions and deferred-scope items to prevent MVP drift.
