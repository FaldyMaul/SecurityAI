# UI Handoff Checklist

## Goal

Provide the minimum checklist needed before UI work is handed to frontend implementation.

## Checklist

- page inventory is approved
- persona navigation is approved
- page-by-page fields are defined
- state labels and badge rules are defined
- role-permission matrix is defined
- wireframes exist for all MVP screens
- empty, loading, error, and retry states are included
- scorecard and ranking patterns are defined
- publication visibility rules are defined
- dependencies on backend fields are listed
- open questions are captured and assigned

## Required Attachments

- sitemap
- wireframes
- state matrix
- permission matrix
- page field list
- API data dependency list
